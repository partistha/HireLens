# HireLens
### AI-Powered Resume Screening and Candidate Ranking System

HireLens is an AI-powered recruitment platform designed to simplify the hiring process through automated resume screening, candidate ranking, and job matching.

## 🌐 Live Project

- **Live Website:** https://hirelens-frontend-z4m5.onrender.com
- **Backend API:** https://hirelens-backend-fulv.onrender.com

## ✨ Key Features

- User Registration and Login
- Recruiter and Candidate Portals
- Resume Upload and Screening
- AI-Based Candidate Ranking
- Job Management
- Candidate-Job Matching
- Application Management

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** MySQL
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas, NumPy
- **NLP:** Natural Language Processing

## 🎯 Project Objective

To make recruitment faster and more efficient by automating resume screening and helping recruiters identify suitable candidates based on job requirements.
